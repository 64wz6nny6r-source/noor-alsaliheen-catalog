# Noor AlSaliheen reciter catalog

Public catalog file read by the Noor AlSaliheen app so reciters can be added or a source paused without an app release.

It contains reciter names and links to recitations hosted by their sources. No user data, secrets or app code.
Rights to each recitation stay with its owners and sources: MP3Quran (mp3quran.net) and EveryAyah (everyayah.com).
